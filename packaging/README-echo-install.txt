Maya Echo ME-24 install (macOS)

1. Drag "Maya Echo ME-24.vst3" into the 1-VST3-folder shortcut (/Library/Audio/Plug-Ins/VST3).
2. Drag "Maya Echo ME-24.component" into the 2-AU-folder shortcut (/Library/Audio/Plug-Ins/Components).
3. Drag "Maya Echo ME-24.app" to 3-Applications to run it standalone.

This build is ad-hoc signed and not notarized. On first launch macOS may block it: right-click the app, choose Open, then confirm. Restart your DAW after installing the plug-in.
